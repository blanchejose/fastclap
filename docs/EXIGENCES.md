## 2. Choix documentés

Choix faits quand l'énoncé était ambigu ou incomplet (section 2.2).

| ID        | Choix                                                                                                                                                                                                                                                                                     |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Annexe A  | Un mot = 5 caractères, espaces compris. Une faute corrigée reste comptée dans la précision.                                                                                                                                                                                               |
| CONF-08   | Mode libre : le joueur avance sur une faute et peut l'effacer ; il arrive quand tout le texte est couvert.                                                                                                                                                                                |
| COURSE-06 | Refusé : lot de plus de 30 touches, plus de 50 touches en 2 s, ou moyenne de plus de 25 touches/s (≈ 300 MPM). Le serveur renvoie alors son état.                                                                                                                                         |
| COURSE-08 | Le délai de 30 s s'applique aussi en salle d'attente : la personne absente est retirée.                                                                                                                                                                                                   |
| SALLE-05  | Une personne qui entre dans une salle pleine devient spectatrice. La capacité ne descend pas sous le nombre actuel de participants.                                                                                                                                                       |
| AUTH-02   | Cookie signé (HMAC-SHA256) de 30 jours, `httpOnly`. Le pseudo d'invité n'a pas à être unique.                                                                                                                                                                                             |
| SALLE-08  | « Personne humaine connectée » = utilisateur avec compte : un invité ne devient jamais hôte. S'il ne reste que des invités, la salle ferme.                                                                                                                                               |
| SALLE-04  | Jeton de 256 bits. Le lien est lié à la personne **et** à son IP, par une mise à jour conditionnelle (deux ouvertures simultanées ne peuvent pas le prendre toutes les deux). L'IP vient de l'en-tête nommé par `TRUST_PROXY_HEADER`.                                                     |
